## Publishing notes

- **Republishing:** build `build/game.rbxl` with `rojo build default.project.json --output build/game.rbxl`, open it in Studio, then File > Publish to Roblox As > update the existing "Blox Champions"; confirm with `MarketplaceService:GetProductInfo(74253300416513).Updated` from the dev place.
- **The publish window:** closing it hangs on "Applying script changes" (the known Studio bug of the Phase 9 record), so its process is ended once the publish is confirmed (the owner's standing request); nothing was lost.
- **A Roblox Player opened before a publish lands runs the old version:** rejoin.
- **Two-player tests:** passes, team switches, leavers, Last Chance and overtime need a second player, so they were played in Studio's local "Clients and Servers" test with a bot driven by probes. In those tests Roblox's own CoreGui can fail on one random client (`Invalid value for enum CreatorType`, then the top bar and player list never load): `game.CreatorType` itself throws there, our code never reads it, and it is a known Studio bug ([DevForum 3130688](https://devforum.roblox.com/t/playerpermissionsmodule-corescript-module-frequently-breaks-causing-cascading-problems/3130688), [DevForum 2971566](https://devforum.roblox.com/t/frequent-coregui-errors-when-testing-local-multiplayer/2971566)); restart the test.
