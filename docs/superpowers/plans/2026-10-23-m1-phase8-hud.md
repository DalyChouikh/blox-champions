# M1 Phase 8 — HUD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Players see the match (spec §11).
- **On screen:** the scoreboard (scores, pips, clock, carrier, lap bar), banners, the event feed, control hints, a speedometer, a reticle, the score tab and the end screen with the MVP.
- **In the world:** the ball's ring, line and ground marker, arrows to the ball and to the carrier's next gate, team-coloured name tags, the call-pass hand, and the goal ring and corner markers glowing.

**Architecture:**
- **The server sends one snapshot of the match after every frame that has rule events** and on every seat change. It carries the score tab, every player's name and the next gate. The client shows the latest snapshot and never computes a rule twice.
- **Pure modules**, unit-tested with exact values, all in `src/shared/Hud`:
  - `HudState` applies snapshots and events, counts the clocks between snapshots, and keeps the banner and the feed;
  - `HudText` writes every string from `Config.UI.text`;
  - `ScreenMarker` places an on-screen marker or pins it to the screen's edge.
- **The screen HUD is React Luau** (Roblox's own, spec A5), rendered by the client `Hud` module through a legacy root. A legacy root renders synchronously, so a change shows in the same frame and tests need no scheduler mocks.
  - React re-renders only when what the HUD shows changes.
  - Text that changes every frame (clock, speed, hint labels) goes through React bindings, set only when it changes.
- **World markers are plain instances** in client modules (`WorldMarkers`, `ArenaGlow`, `NameTags`), because they follow world positions every frame. They work like Phase 7's touch controls.
- **One frame order:** `FrameController.render` steps camera → touch controls → HudStore → Hud → WorldMarkers → ArenaGlow → NameTags.

**Tech Stack:**
- Luau (`--!strict`), Rojo 7.7.1, StyLua 2.6.0, selene 0.32.0, luau-lsp 1.70.1 (`bash scripts/analyze.sh`).
- **Jest Roblox 3.20.1** (`roblox/jest`, `roblox/jest-globals`) through the Roblox Studio MCP.
- **React Luau 17.3.13** (`roblox/react`, `roblox/react-roblox`). Both switch in Task 1 (spec A5).

1. **A player who joins mid-match** (or comes back) sees the right score, clock, lap bar, and a score tab that names players who already left.
   - Task 2: `sends a snapshot to everyone whenever a seat changes, naming every player who ever joined`.

2. **A goal, then the kickoff.** GOAL! shows through the celebration, the 3-2-1 replaces it, and the clock stays frozen through both.
   - Task 4: `counts the clock down while live and holds it through kickoffs and celebrations`, `counts down the kickoff in a banner, 3-2-1`.
3. **Overtime and Last Chance.** The clock counts up under OVERTIME, and 0:00 holds during Last Chance.
   - Task 4: `counts overtime up, and holds 0:00 in Last Chance`.
   - Task 6: `says OVERTIME in overtime`.
4. **A spectator, or a dead ball.** With no character there is no speed and no hints. With no ball (kickoff) every ball marker hides, with no error.
   - Task 8: `shows the speed in km/h, and nothing for a spectator`, `shows control hints with a keyboard or a gamepad, none on touch or without a character`.
   - Task 10: `hides every ball marker while there is no ball`.
5. **The device changes mid-play.** Hints switch between key names and glyphs, and on touch they hide and the score button shows.
   - Task 8: the hints test.
   - Task 9: `opens the score tab while its key is held, and toggles it with the touch button`.

## Decisions not spelled out in the spec (for owner review)

1. **The server sends the snapshot after every frame with rule events and on every seat change** (decision 1 of the Architecture). It includes the score tab's stats and every name, so the HUD repeats no rule. Cost if wrong: a few hundred bytes per event frame.
2. **The client counts the clock between snapshots with the engine's own rule** (`MatchClock.runs`). Each snapshot and each `ClockWarning` resets it. Cost if wrong: up to a frame of drift until the next snapshot.
3. **Screen HUD in React, world markers in plain instances** (Architecture). Cost if wrong: the art pass restyles two kinds of UI, as it already does for the touch controls.
4. **The lap label counts completed laps:** "Lap n/4" (n = the streak) while the four segments fill for the gates crossed this lap. Once the goal is open for that team it reads "Streak n/12". Cost if wrong: a label change.
5. **A streak point gets its own banner**, "STREAK POINT!", like GOAL! (spec §11.1 lists GOAL! only). Cost if wrong: one banner.
6. **The goal panel's slide is client-side.** Each client slides the panel out of the ring while the goal is open and back when it closes. The server keeps only its collision (it no longer hides it). Cost if wrong: none.
7. **Hints show the current device's key.**
   - With a keyboard: the key's name on the player's own layout (Roblox's `GetStringForKeyCode`), or `Config.UI.keyNames` where Roblox gives none, then the KeyCode's name.
   - With a gamepad: Roblox's glyph image.
   - On touch there are no hints, because the buttons carry labels.
   - Cost if wrong: none.
8. **Jump hides from the hints and the touch buttons while airborne** (a jump needs the ground). One rule serves both. Cost if wrong: the touch Jump button blinks during a jump.
9. **The touch throw button rings while Ball Focus is on** (Phase 7 ruling D9). Cost if wrong: visual.
10. **Gamepad Select opens the score tab**, so `RobloxDefaults` turns off `GuiService.AutoSelectGuiEnabled`. Cost if wrong: Select no longer jumps into Roblox's menu navigation; M1 has no navigable menus.
11. **The cursor hides while the mouse is locked**, and the reticle stands in for it. It shows whenever the mouse is free. Cost if wrong: none.
12. **Your own name tag is hidden.** The call-pass hand shows over teammates only, as spec §11.1 says. Cost if wrong: none.
13. **The end screen** shows the winner, the MVP's card (name, score, goals, assists, saves), both teams' totals and the score tab. It stays until the next match's first snapshot.
    - It has no avatar picture: that needs a web call, and the player card comes in M8.
    - Cost if wrong: one image later.
14. **The ball indicator also rings a ball you carry.** Spec §9.4 says "always". Cost if wrong: one condition.

**Not in this phase:**
- **Phase 9:** the Open Cloud CI job (Roblox Jest now supports it), multi-client and real-device playtests (including gamepad Select and glyphs), and tuning every HUD number.
- **Art pass:** the HUD's look, images and animations.
- **M6:** settings (hint visibility, units).
